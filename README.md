# 基础物理实验（2026 秋）

北京大学 2026 秋季学期《基础物理实验》课程网站（静态站点，GitHub Pages 托管）。

## 内容
- **每周实验安排（第三组专属）**：校历第 1–16 周第三组（工学）的实验与上课教室，自动高亮「下一节课」；附全部 6 组完整循环表（第三组整列高亮）。
- **预习问题 & 实验报告要求**：`4a` 全部 18 个实验的重点预习、预习思考题、数据处理与报告要求全文录入，含提交时机与对应周次；另收录 `5` 课堂记录规范、`4d` 误差作业题目与原始数据表格。支持关键词搜索、按「我的课表 / 要交预习报告」筛选、锚点直达，无需再打开 PDF。
- **实验地点对照**：每个实验对应的房间号，按楼宇（南楼 / 新奥工学大楼 B2 / 西楼）颜色标注。
- **实验室路线**：新奥工学大楼地下二层到达方式。
- **上课须知要点**：考勤、预习、实验、报告、评分、请假补课。
- **责任教师与联系方式**：高亮第三组相关教师。
- **资料下载**：课程文件包全部 PDF 原件。

> 说明：分组名单与同学邮箱因隐私未公开；最终安排以任课教师与微信群通知为准。

## 本地预览
```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 重新生成页面
`tools/gen_prep.py` 保存了「预习 & 报告要求」区块的结构化数据，来源为课程文件包中的 `4a`（预习和实验报告要求）、`5`（课堂记录要求）、`4d`（误差数据处理题目）三份 PDF。课程要求有变动时，改脚本里的 `EXPS` / `NOTES_HTML` 后运行：

```bash
python3 tools/gen_prep.py
```

脚本幂等：重复运行不会改动页面，也不会重复插入导航项。其余区块（课表、地点对照、须知、教师、资料下载）直接编辑 `index.html` 即可。
