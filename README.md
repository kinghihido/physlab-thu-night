# 基础物理实验 · 周四晚班（2026 秋）

北京大学 2026 秋季学期《基础物理实验》周四晚班课程网站（静态站点，GitHub Pages 托管）。

## 内容
- **每周实验安排**：校历第 1–16 周的全部实验与上课教室，自动高亮「下一节课」。
- **实验地点对照**：每个实验对应的房间号，按楼宇（南楼 / 新奥工学大楼 B2 / 西楼）颜色标注。
- **实验室路线**：新奥工学大楼地下二层到达方式。
- **上课须知要点**：考勤、预习、实验、报告、评分、请假补课。
- **责任教师与联系方式**。
- **资料下载**：课程文件包全部 PDF 原件。

> 说明：分组名单与同学邮箱因隐私未公开；最终安排以任课教师与微信群通知为准。

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
